# StripMap Editor

Strip Map 데이터 관리 시스템

## 주요 기능

- LOT ID 변경
- MapArray 수정/논리 삭제
- PCB 2D ID 원복/물리 삭제

## 기술 스택

- C# / .NET Framework
- WinForms
- SQL Server
- Stored Procedure 연동

## 개발 환경

- Visual Studio 2019
- SQL Server 2019+

## 설치 방법

1. Repository 클론
2. config.ini 설정 (DB 접속 정보)
3. SQL Server에 SP 설치
4. 빌드 및 실행
